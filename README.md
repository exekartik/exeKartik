# Kartik Singh — Portfolio

Personal developer portfolio and interactive showcase built with Next.js 16, React 19, Tailwind CSS v4, and Framer Motion.

## 🚀 Live Site
- [exeKartik Repository](https://github.com/exekartik/exeKartik)

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, shadcn/ui
- **Animations**: Framer Motion
- **Package Manager**: pnpm

## 📦 Features
- Interactive project showcase with live motion previews
- Experience & education timeline
- Technical articles and blogs section (Medium & Hashnode integration)
- Dark / Light mode with smooth theme transitions
- Responsive & accessible modern UI

## 💻 Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```
